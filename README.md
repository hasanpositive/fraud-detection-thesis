# Financial Fraud Detection Using Machine Learning

## Master's Thesis | NUST MISIS | 2026

###  Overview
This repository contains the complete code and results for my master's thesis on financial fraud detection. The research evaluates multiple machine learning models across three diverse datasets with fraud rates ranging from 0.13% to 3.5%.

### Author
**Hasan** | Data Science Master's Student | NUST MISIS, Moscow

###  Key Results
| Dataset | Fraud Rate | Best Model | F2-Score | Recall | Precision |
|---------|------------|------------|----------|--------|-----------|
| IEEE-CIS | 3.50% | XGBoost | 0.6492 | 79.2% | 37.8% |
| Credit Card | 0.17% | XGBoost | 0.8660 | 85.7% | 90.3% |
| Synthetic | 0.13% | XGBoost | 0.4120 | 65.3% | 16.6% |
